# DevPilot Studio v1.2.0 Release Notes

We are thrilled to announce the official release of **DevPilot Studio v1.2.0**! This release brings a massive overhaul to the documentation, several quality-of-life improvements, and visual refinements.

## ✨ What's New

### Massive Documentation Overhaul
- **Brand New README**: Completely rewritten to be production-ready with a beautiful hero section, badges, a dynamic Mermaid architecture diagram, and comprehensive feature tables.
- **7 Professional Guides in `docs/`**:
  - `INSTALL.md`: Deep dive into installation paths (Marketplace, NPX, curl, source).
  - `CONFIGURATION.md`: Exhaustive reference of every `DPS_*` environment variable.
  - `ARCHITECTURE.md`: Technical blueprint and sequence diagram of the rendering engine.
  - `DEVELOPMENT.md`: Testing, linting, and POSIX constraints for contributors.
  - `SECURITY.md`: Formal audit report confirming 100% offline privacy and zero telemetry.
  - `FAQ.md`: Troubleshooting answers for rate limits and platform support.
  - `CONTRIBUTING.md`: PR guidelines, code of conduct, and commit conventions.

### Visual & Layout Refinements
- **Balanced Logo Dimensions**: Reduced the logo width to `350px` to prevent viewport takeover on GitHub, ensuring a cleaner layout.
- **Terminal Text Preview**: Added an exact raw text representation of the Vivid theme (`shaded` blocks) directly in the README for quick reference.

### Cleanup
- Removed legacy, unformatted documentation files (`docs/INSTALLATION.md`, `docs/DEVELOPER.md`, `docs/TROUBLESHOOTING.md`, `SECURITY-AUDIT.md`) to prevent duplication and confusion.
